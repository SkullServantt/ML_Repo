# Miguel Lobo — Honda Motovix Serra

Site Next.js recriado com:
- Miguel Lobo como consultor Honda;
- endereço da Motovix Serra;
- WhatsApp e Instagram fornecidos;
- quatro fotos do Miguel enviadas pelo usuário;
- catálogo visual de motos;
- imagens de modelos apontando para a Sala de Imprensa Honda;
- botões de interesse direcionando para o WhatsApp;
- visual minimalista, glassy e inspirado nas cores Honda.

## Rodar
npm install
npm run dev

Abra http://localhost:3000

## Observação sobre imagens das motos
As imagens dos modelos usadas no catálogo apontam para arquivos públicos da Sala de Imprensa Honda. A lista de modelos e preços de referência foi montada a partir do catálogo oficial Honda consultado em 01/10/2026. Confirme preço, versão, frete e disponibilidade com a concessionária antes de publicar uma oferta específica.
